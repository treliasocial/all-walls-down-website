# Styling

The portal should use the AWD visual language: dark background, gold accents, serif headings, restrained cards, and clear operational layouts.

Rules:

- Public website design remains intact.
- Portal UI should be dense, readable, and work-focused.
- Avoid marketing hero layouts inside the management portal.
- Use clear focus/hover states.
- Keep mobile layouts usable.
- Use existing CSS variables where possible.

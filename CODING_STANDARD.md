# Coding Standard

- Keep public-site code separate from portal code.
- Keep shared utilities in `src/shared`.
- Keep privileged operations in server routes with server-side authorization.
- Do not use browser localStorage as the source of truth for staff/admin data.
- Use semantic HTML and accessible labels for forms.
- Avoid hard-coded secrets and deploy-only credentials.
- Keep Release 1 changes focused on secure portal foundation.
